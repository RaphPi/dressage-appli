# Ma reprise — appli iPhone

Appli web hors-ligne pour apprendre une reprise de dressage par cœur (projet personnel).

Elle ne contient **aucune reprise ni aucune donnée personnelle**. Les reprises arrivent sous forme de « paquets » `.html`, préparés sur l'ordinateur puis importés dans l'appli. Notes, étoiles et réglages restent dans le téléphone.

## Installer sur iPhone

1. Ouvrir https://raphpi.github.io/dressage-appli/ dans **Safari**.
2. Toucher **Partager**, puis **Sur l'écran d'accueil**.
3. Lancer « Ma reprise » depuis l'écran d'accueil, puis toucher **Importer un paquet**.

Après la première ouverture, l'appli fonctionne sans réseau.
